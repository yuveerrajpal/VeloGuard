# Data

Raw data files are not committed to this repository.

## Bike&Safe Dataset
Real-world bicycle IMU data — accelerometer, gyroscope, magnetometer, GPS.
Recorded from a smartphone mounted on a bicycle handlebar across 3 routes, 9 laps.
811,781 samples at 50Hz.

**Source:** Blauth da Silva, G.; Tavares, J. (2022)  
Bike&Safe Dataset, Mendeley Data, V2  
https://data.mendeley.com/datasets/3j9yh8znj4/2

Download and place under `data/BikeAndSafe/` then run `baseline_analysis.py`.

## Qubo IoT Data
Accelerometer data from vehicle IoT testing, used to validate threshold methodology.
Proprietary — not publicly available. Used with permission from Qubo.
